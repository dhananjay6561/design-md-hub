Guardrails
DO
Use purple (#7047EB) as the single primary action color for all CTAs
Use Circular XX for all headings, Inter for all body and UI text
Keep cards at #F7F7F8 in light mode — the subtle contrast from #FFF creates depth
Use the lemon yellow (#FFC233) only for the brand icon mark and decorative accents
Dark bg is #121217 — a near-black with purple-blue undertone matching the brand
DON'T
Don't use lemon yellow as a button or interactive element color — it's icon-only
Don't use Circular XX below 16px — use Inter for all small/label text
Don't use pure #000000 for text — always #121217 (warm dark with purple undertone)
Don't use green or blue as CTA colors — purple owns that role in this system
Don't stack pink + plum + yellow gradients in a single UI region — one accent at a time
