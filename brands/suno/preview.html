Do
Keep the canvas dark warm #101012 (light = warm paper #F7F4EF) — neutrals are warm, never cold grey.
Reserve the orange→pink gradient for the one Create action.
Let the accent spectrum carry song / genre / album variety.
Set the hero statement in PP Editorial New serif; everything else in PP Neue Montreal.
Don't
Use cold grey neutrals — the "dumbo" scale is warm.
Put the Create gradient on secondary buttons, or use two gradient buttons per view.
Set body or UI in the serif — it's display-only.
Generate album art or waveforms with Math.random — keep them deterministic.
