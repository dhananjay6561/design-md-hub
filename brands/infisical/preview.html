DO
Use volt (#f5f841) as the H1 highlight marker — words in a box, not gradient text
Use void (#000000) as CTA background with volt text
Use JetBrains Mono for all secret keys, values, paths, and IDs
Mask all secret values by default — reveal is an explicit user action
Default to light mode — #f3f4f6 page bg, white surfaces
Use AllianceNo2 for all marketing and UI text
DON'T
Don't use volt for warning/error states — it's a brand color, not a semantic one
Don't use Inter or any other font — AllianceNo2 is the brand font
Don't show unmasked secrets in list views, logs, or error messages
Don't default to dark mode — the primary experience is light
Don't round corners above 8px on cards; use 6px on buttons
Don't add more than 20 secret rows in interactive tables
