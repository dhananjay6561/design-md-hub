Do
Keep a bright white, warm canvas with a warm near-black ink — light is primary.
Use one orange (#FC5200) for logo, CTAs, links and the active flow path.
Set marketing display headings in Newsreader (serif); keep UI & body in Inter.
Make lifecycle loops literal — Trigger → Timer → Send → Filter → Exit, a contact flowing through.
Treat amber / violet / green / slate as functional signals only.
Don't
Lead with a dark or cold canvas, or a second brand hue competing with the orange.
Set UI, labels or node cards in the serif — the serif is marketing display only.
Render the loop as a flat list — the value is the branch and its paths.
Make orange neon or garish — it's one confident hot-orange, warmed by coral.
Swap the spiral loop mark for a generic envelope.
