DO

Use purple (#A259FF) exclusively as a brand accent — not for informational states (use blue for info).
Keep backgrounds neutral (#FFFFFF, #F5F5F5) and let illustrations carry color.
Use semantic tokens over raw hex values in plugin and product code.
Ensure minimum 4.5:1 contrast ratio between text and background at all times.
Apply shadow-focus (blue ring) on interactive elements for keyboard accessibility.
Use #F24822 (Figma Red) consistently for all destructive and error states.

DON'T

Don't use brand purple or blue as full-surface backgrounds on large areas — accents only.
Don't mix Figma Sans with other grotesque sans-serifs in the same composition.
Don't use decorative shadows on app UI components — reserve for floating surfaces.
Don't use full black #000000 for text — the system uses #000000E5 (90% opacity).
Don't rely on color alone to communicate state — pair with icon, label, or shape change.
Don't exceed 6 colors in a single component or layout section.
