DO
Use purple (#A259FF) as brand accent — not for informational states (use blue for info)
Keep backgrounds neutral (#FFFFFF, #F5F5F5) and let illustrations carry color
Apply semantic tokens over raw hex values in plugin and product code
Show blue focus ring on all interactive elements for keyboard accessibility
Use #F24822 (Figma Red) consistently for all destructive and error states
DON'T
Use brand purple or blue as full-surface backgrounds — accents only
Use decorative shadows on flat app UI — reserve for floating surfaces and modals
Use full black #000000 for text — the system uses rgba(0,0,0,0.9)
Rely on color alone to communicate state — always pair with icon, label, or shape
Exceed 6 colors in a single component or layout section
