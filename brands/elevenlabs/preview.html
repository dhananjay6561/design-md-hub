Guardrails
DO
Keep the shell monochrome — ink #000/#1C1C1C on eggshell #FDFCFC (light) or #0F1117 (dark)
Use the categorical ramps for voices, languages, waveforms and states — not as one brand hue
Make primary buttons the ink color (black on light, white on dark), not a colored accent
Use Waldenburg for display and UI; Geist Mono only for model IDs, code and metrics
Use real model IDs (eleven_multilingual_v2, eleven_turbo_v2_5, eleven_v3) and real voice names
DON'T
Invent a single "ElevenLabs brand color" — the brand is monochrome, the scale is categorical
Use #000 for text on the dark surface — flip to #FFFFFF
Over-saturate dark surfaces; step within the real neutral ramp (#0F1117 → #1C1C1C → #3D3D3D)
Mix Waldenburg into code/metadata or Geist Mono into headings
Derive the waveform from Math.random() — it must be deterministic from the input text
