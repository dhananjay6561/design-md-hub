DO

Use #228df2 as the one and only chromatic colour in the app UI. All other colour is semantic status.
Keep all app surfaces within the #141414–#1d1d1d range. Never introduce mid-grey or coloured backgrounds.
Render all code in Berkeley Mono — in editor, chat bubbles, tooltips, and inline diffs.
Use Cursor Gothic (Inter Tight) exclusively for brand and marketing text — never inside the editor.
Maintain 95%+ achromatic coverage on any surface. Chromatic colours are states, not backgrounds.
Use pill (9999px) radius for marketing buttons and strict 4px/8px for IDE UI elements.

DON'T

Don't use gradients, drop shadows, or coloured glows in the app UI. Depth is implied by background value alone.
Don't use orange (#f54e00) inside the IDE — that accent is marketing-only.
Don't mix light UI widgets into a dark theme context or vice versa.
Don't use #000000 pure black for any text — use warm near-black (#26251E) on marketing, #141414 for UI rails.
Don't place more than one chromatic accent per screen in the IDE. Blue is for primary action only.
Don't animate layout transitions in the editor. Micro-animations only in chat stream and diff application.
