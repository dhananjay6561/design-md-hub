Design System

Guardrails

Rules from Doppler's live design patterns — what to always do, and what to never do.

  • 01 DopplerRepro only for display text. Never substitute Inter or system fonts at display sizes. DopplerRepro's proportions are part of the brand identity.
  • 02 Dark mode background is #1C1624. Never use pure black or generic dark grays. The deep purple-near-black is canonical.
  • 03 Cream, not white. Light mode background is #FCFAF6 (warm cream). Pure white reads as cold and off-brand.
  • 04 Gradient belongs only to the mark. The pink→orange→purple gradient is the logo icon only. Never apply it to buttons, text, or UI chrome.
  • 05 Regular weight headings. DopplerRepro at 400 weight reads as visually strong. Setting headings to 700 becomes heavy and off-brand.
  • 06 Production is green, never red. Green (#00F575) signals the production environment. Red is reserved exclusively for errors and destructive actions.
  • 07 Secret values are masked by default. Never render secret values as plaintext on initial load. Reveal only on explicit user interaction.
  • 08 #6B13F5 is the only valid CTA color. Do not substitute indigo (#4F46E5), violet (#7C3AED), or any other purple. The exact brand purple is non-negotiable.
  • 09 Mono font for all secrets. Every secret key and value must render in DopplerReproMono. Proportional fonts break the security-first visual contract.
  • 10 Use the full 3-stop gradient. Single-stop purple or orange alone reads as generic. The gradient is always pink→orange→purple, all three stops.
