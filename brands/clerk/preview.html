05 · Guardrails

Design Principles

Rules that keep every Clerk-powered UI trustworthy, focused, and accessible. These are non-negotiable.

✓ Do
  • ✓ Prioritize trust signals — use consistent borders, clean spacing, accessible contrast ratios throughout
  • ✓ Use violet only for the single primary action per view — one CTA to rule them all
  • ✓ Keep auth components tight and focused — no distractions during sign-in flows
  • ✓ Show clear error states with actionable, human-readable messages
✗ Don't
  • ✗ Use more than one primary button per screen — violet has one job at a time
  • ✗ Add decorative backgrounds to auth pages — plain white or subtle gray only
  • ✗ Show technical error codes to end users — translate to plain language always
  • ✗ Use animations that delay the form becoming interactive — no motion tax on auth
  • ✗ Use all-caps labels or uppercase text anywhere in the UI
