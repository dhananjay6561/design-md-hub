Guardrails
DO
Use indigo #635DFF as the one primary — the current Auth0 brand color
Keep page backgrounds warm paper #FFFEFA; let indigo carry emphasis
Keep the shield mark monochrome on paper, white, or dark
Use neutral near-black #111111 for dark surfaces — not navy
Use teal #4CB7A3 only for genuine authenticated / success states
DON'T
Use the legacy orange #EB5424 — Auth0 rebranded to indigo
Tint dark surfaces blue/navy — Auth0's dark is neutral gray-black
Set display headings in Roboto Mono or the body font
Overload the login widget — one primary action, providers secondary
Fake provider names — use real IdPs (Google, GitHub, Microsoft)
