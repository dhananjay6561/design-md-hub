Do

        

          
Anchor on a near-black canvas with one electric blue (#1488FC) and a faint blue aurora.

          
Give the prompt box its blue glow and bright light-streak — the signature energy.

          
Make the flow prompt → run → preview: write files, actually run a terminal, flip to a live preview.

          
Set the bolt wordmark in bold italic; UI in Inter, code in JetBrains Mono.

          
Keep the editor & terminal always dark with GitHub-style syntax colors.

        

      

      

        
Don't

        

          
Use a light canvas as the primary identity — Bolt is dark & electric (light is secondary).

          
Introduce a second brand hue; blue is the only accent (syntax/status are functional).

          
Present Bolt as just a code generator — show that it runs & deploys.

          
Over-glow everything — the streak + card glow are focal; the rest stays matte.

          
Set the wordmark upright or light — the forward italic lean is the character.
