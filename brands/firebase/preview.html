Guardrails
Do
  • Color-code Firebase products consistently across UI
  • Use monospace for security rules, paths, and JSON
  • Show quota usage with visual progress bars
  • Use amber #FFCA28 as both brand and warning color
  • Use flame gradient only in hero/marketing contexts
Don't
  • Don't use amber/orange as a background fill
  • Don't mix multiple product colors in one view
  • Don't use sharp corners — Firebase is approachable
  • Don't use red for anything except delete and critical errors
  • Don't use small fonts for security rules
