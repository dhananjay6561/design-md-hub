05 — Spacing

Spacing Scale

Base unit is 8px. All values are multiples or half-multiples. 8px between items in a group, 16px between groups, 32–40px between components, 64–96px between sections.

06 — Tone & Guardrails

Dos & Don'ts

These rules define the Vercel aesthetic. Following them ensures the system reads as authoritative, fast, and engineering-driven.

✓ DO
  • Use #171717 (not #000000) for body text in light mode — avoids optical harshness
  • Use shadow-based borders (box-shadow: 0 0 0 1px rgba(0,0,0,0.08)) on cards and components
  • Apply the 2px white gap + 2px blue ring focus pattern for all keyboard targets
  • Reserve blue accent (#0070f3) for exactly one primary action per view
  • Use 9999px radius only for badges and pills — never standard buttons
  • Maintain consistent spacing using the 8px grid; all values must be multiples of 4px minimum
  • Use Geist Mono for all code, CLI output, env var names, deployment IDs, and numeric dashboards
  • Keep motion fast: 150ms for micro-interactions, 200ms for popovers, 300ms for page overlays
  • Apply prefers-reduced-motion to all transitions and animations
  • Use WCAG AA contrast (4.5:1) as the minimum; AA+ (7:1) for primary body text
✕ DON'T
  • Don't use gradients on interactive UI — marketing hero backgrounds are the sole exception
  • Don't use more than one accent color per view
  • Don't apply drop shadows for elevation on cards — use the ring-border shadow technique
  • Don't mix border-radius families within a single view (e.g. 6px and 12px in the same card group)
  • Don't use color to convey meaning without a secondary indicator (icon or text label)
  • Don't center-align multi-line body text or lists
  • Don't use font weights other than 400, 500, and 600
  • Don't add decorative illustrations, stock photos, or abstract graphics in dashboard UI
  • Don't animate layout properties (width, height, top, left) — animate only transform and opacity
  • Don't use the pill radius (9999px) on primary CTA buttons — reads as friendly, not authoritative
