Guardrails
Do
  • Use IBM Plex Mono for all event IDs, hashes, and stack traces
  • Color-code severity consistently — level dots, badges, and accents must align
  • Show timestamps as relative ("2 hours ago") with absolute datetime on hover
  • Keep error messages technically accurate — developers need precision over hand-holding
  • Use blurple (#6a5fc1) as the primary action color and for info-level events
  • Reserve hot-pink / lt-pink gradients for marketing surfaces only
Don't
  • Don't apply bright brand colors to large surface areas — they are status indicators
  • Don't exceed 8px border-radius on data tables or dashboards — stay sharp
  • Don't repurpose the error color (#c73852) for non-error UI states
  • Don't animate issue rows — performance tables demand focus, not delight
  • Don't override the dark primary surface (#1f1633) for the main dashboard view
  • Don't stack multiple accent colors in a single component
