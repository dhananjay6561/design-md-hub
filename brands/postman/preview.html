Guardrails
DO
Use orange #FF6C37 for the Send button and primary CTAs — it is the brand
Color HTTP methods semantically: GET green, POST amber, PUT blue, PATCH purple, DELETE red
Set URLs, JSON, and method labels in IBM Plex Mono — the payload is code
Set headings in Degular (≈ Figtree), UI in Inter
Show status + time + size on every response — the Postman readout
DON'T
Recolor the Postmanaut mark — it's fixed orange + white
Use a method's color for a different verb — GET is green, never orange
Set JSON or URLs in a sans — mono carries the payload
Render a response without a status pill — status is always shown
Fabricate responses — use realistic shapes and correct status codes
