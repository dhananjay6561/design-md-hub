Guardrails

DO

  • Color-code HTTP methods consistently across all views
  • Use orange only for the primary Send/submit action
  • Show status codes prominently — they're the key signal
  • Use mono for URLs, headers, and request/response bodies
  • Show response time on every request

DON'T

  • Don't use the same color for different HTTP methods
  • Don't hide the response status code
  • Don't wrap URLs — keep on one line with scroll
  • Don't truncate JSON response bodies
  • Don't mix sans-serif and mono in the same code block
