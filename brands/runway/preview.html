Guardrails
DO
Keep surfaces monochrome — warm off-white #EFEEE6 paper and off-black #0C0C0C ink carry the brand.
Reserve the serif (Times Now ≈) for hero and display only; everything functional is ABC Normal.
Preserve the warm off-white tint #EFEEE6 — never flatten it to pure #FFFFFF.
Let generated media supply all the color; the chrome stays neutral.
Use real model names exactly — Gen-4.5, Gen-4 Turbo, Act-Two, Aleph.
DON'T
Introduce a brand accent color — Runway has no green/blue/orange brand hue.
Recolor the wordmark or add a gradient to it.
Use the serif for body, labels, or UI text.
Default to pure #000 / #fff where the off-black / off-white tokens apply.
Communicate state with saturated color chips — use neutrals, motion, and copy.
