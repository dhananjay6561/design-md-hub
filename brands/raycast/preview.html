05 — Tone & Guardrails

Do's & Don'ts

These rules define what Raycast is and what it isn't. Follow them to keep every screen coherent.

Do
  • ✓ Use the surface ladder (background → panel → elevated) for depth.
  • ✓ Keep saturated accent colors on data and status — never on navigation chrome.
  • ✓ Restrict gradients to the window background and one hero stripe per marketing page.
  • ✓ Use Inter with ss03 on web; SF Pro (system-ui) in native contexts.
  • ✓ Maintain 40 px row heights for keyboard-navigable lists.
  • ✓ Apply selection color to both the loader bar and selected-row highlight.
  • ✓ Use inset 0 0 0 1px border-shadow on floating containers.
  • ✓ Let backdrop-filter: blur(72px) carry the frosted-glass effect.
Don't
  • ✕ Add drop shadows to cards, panels, or popups — elevation is color, not shadow.
  • ✕ Use the red/orange brand gradient on interactive elements like buttons or tabs.
  • ✕ Mix multiple accent hues on a single screen's chrome elements.
  • ✕ Use font weights above 600 inside the app window.
  • ✕ Add decorative corners below 6 px or above 18 px except for pill buttons.
  • ✕ Add hover backgrounds to list items unless keyboard-focused or selected.
  • ✕ Use more than one gradient direction per view — window backgrounds are top-to-bottom only.
  • ✕ Render Raycast-style UI inside a scrollable, multi-column layout.
