Guardrails

Do

  • Use the surface ladder (bg → surface → elevated) instead of shadows for depth
  • Keep saturated accent colors on data/status — never on navigation chrome
  • Restrict gradients to window backgrounds only
  • Maintain 40px row heights for keyboard-navigable lists
  • Apply the selection color consistently to loader bar and selected-row highlight
  • Use inset box-shadow on floating containers instead of outlines

Don't

  • Don't add drop shadows to cards, panels, or popups — elevation is color, not shadow
  • Don't use the red/orange brand color on interactive button elements
  • Don't mix multiple accent hues on a single screen's chrome elements
  • Don't use font weights above 600 inside the app window
  • Don't add hover backgrounds to list items unless keyboard-focused or selected
  • Don't use gradient text on headings or body copy
