DO

  • Use monospace for all query text and identifiers
  • Use teal exclusively for primary actions and active states
  • Layer backgrounds: base → surface → elevated
  • Show type badges on every column in schema view
  • Color-code GraphQL syntax tokens consistently

DON'T

  • Don't use rounded corners > 8px — too soft for a DB tool
  • Don't color other elements teal — it signals "action"
  • Don't show raw SQL unless explicitly toggled
  • Don't use animations > 250ms in query workflows
  • Don't mix UI font and mono in the same label
