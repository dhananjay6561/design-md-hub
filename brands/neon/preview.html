06 — Guardrails

Do's & Don'ts

Design principles that keep Neon's interface sharp, technical, and trustworthy.

✓
Do
  • Use green accent only for CTAs, active states, and success
  • Prefer monospace for all technical values — IDs, branches, SQL
  • Keep backgrounds layered — depth via color steps, not shadows
  • Make metrics and numbers the visual hero on dashboard screens
✕
Don't
  • Use the green glow decoratively — only on interactive focus
  • Add rounded corners above 8px — keep the UI sharp
  • Use light mode as the primary experience
  • Add illustrations or marketing visuals inside the dashboard
  • Show loading spinners where skeleton screens work better
