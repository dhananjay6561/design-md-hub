Guardrails

DO
Maximize information density — small text and tight spacing are features

Keep forms compact — Retool users are power users
Use data tables as the default pattern for list data
DON'T
Add rounded corners above 6px — enterprise convention
Use decorative visuals, illustrations, or gradients
Animate canvas interactions — performance over delight
Use dark mode — Retool is light-first
Add whitespace that doesn't serve information hierarchy
