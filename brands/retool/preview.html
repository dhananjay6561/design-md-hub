-- Fetch active users with recent orders
SELECT
  u.id,
  u.email,
  u.created_at,
  COUNT(o.id) AS order_count
FROM users u
LEFT JOIN orders o ON o.user_id = u.id
WHERE u.active = true
  AND u.created_at > '2024-01-01'
GROUP BY u.id, u.email, u.created_at
ORDER BY order_count DESC
LIMIT 100;

05 · Guardrails

Design Principles

Retool is a power user's tool. Every design decision should serve information density, speed, and clarity — not decoration.

✓ Do
  • ✓ Maximize information density — small text and tight spacing are intentional features
  • ✓ Use the blue accent only for selection, focus states, and the single primary CTA
  • ✓ Keep forms compact — Retool users are power users who know their workflows
  • ✓ Use data tables as the default pattern for any list data
✗ Don't
  • ✗ Add rounded corners above 6px — enterprise convention, full stop
  • ✗ Use decorative visuals, illustrations, or gradients anywhere in the product
  • ✗ Animate canvas interactions — performance over delight, always
  • ✗ Use dark mode — Retool is light-first and light-only
  • ✗ Add whitespace that doesn't serve information hierarchy — earn every pixel
