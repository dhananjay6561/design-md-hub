05 / Guardrails
Do & Don't
Do
Anchor on the purple-black canvas #0E0918; light it with the orange→red gradient
Darken orange-red to #E8330F for text/links on light surfaces
Set the UI in Geomanist (≈ Manrope); reserve mono for expressions
Color nodes by type; mark execution with green + item counts
Don't
Don't use a plain black/grey canvas — purple-black is the n8n signal
Don't put orange text on the orange button
Don't invent node data — use real n8n language (Trigger, IF, items, {{ }})
Don't use Math.random — keep the execution deterministic
