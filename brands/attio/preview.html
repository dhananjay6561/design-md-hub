Guardrails
Do
Keep the canvas near-white #fff / near-black #101010 and let the data carry the color.
Reserve blue #266df0 for links, selection, and focus rings.
Make primary buttons ink; invert --btn-text per theme so contrast never breaks.
Build UI as typed cells on 1px hairline grids — Attio is a database you can see.
Color status by meaning: green won, red lost, yellow pending, grey lead.
Don't
Don't turn the accent blue into a button fill or a background wash.
Don't lean on drop shadows for structure — use 1px strokes.
Don't set body, cells, or labels in a serif — Tiempos is a rare editorial accent.
Don't invent dark-mode tints; step through the real black-* ramp.
Don't add a second saturated hue beyond the semantic three.
