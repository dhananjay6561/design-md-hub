05 — Tone & Guardrails

Tone & Guardrails

These rules preserve the calm, document-like character of Notion. Every design decision should pass this checklist.

DO
  • ✓Use #37352F for reading text — never pure black.
  • ✓Use warm off-white #F7F6F3 for sidebar and secondary surfaces.
  • ✓Apply the 8px grid strictly; every spacing value is a multiple of 4px.
  • ✓Use Inter weight 500 for all UI labels and interactive text.
  • ✓Use the 10-color content palette for semantic tagging.
  • ✓Keep shadows extremely subtle — nearly flat elevation.
  • ✓Use border-radius: 8px on cards and 4px on form controls.
  • ✓Hide secondary actions behind hover/focus states.
  • ✓Maintain content max-width of 720px on standard pages.
  • ✓Use transition: 120ms ease for hover state changes.
DON'T
  • ✗Don't use pure #000000 black for text.
  • ✗Don't apply aggressive drop shadows or heavy borders.
  • ✗Don't use more than two typefaces at once.
  • ✗Don't use color as decoration — every color must signal state or type.
  • ✗Don't introduce colors outside the 10-color palette and CTA blue.
  • ✗Don't use font weights above 700 or below 400.
  • ✗Don't make secondary controls permanently visible.
  • ✗Don't use border-radius values outside the token table (no 6px, 10px, 16px).
  • ✗Don't use spacing values that aren't multiples of 4px.
  • ✗Don't add animation beyond simple opacity/transform at ≤ 200ms.
  • ✗Don't center-align body text — all prose is left-aligned.
  • ✗Don't use color-only status indicators — always pair with icon or text.
