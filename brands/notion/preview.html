Guardrails
DO
Use text-primary (#37352F) for reading text — never pure black
Use warm off-white (#F7F6F3) for sidebar and secondary surfaces
Apply the 8px grid strictly — every spacing value must be a multiple of 4px
Keep shadows extremely subtle — less than you think is needed
Use border-radius: 8px on card-like containers, 4px on form controls
DON'T
Use pure #000000 black for text — Notion's ink is warm near-black #37352F
Apply aggressive drop shadows or heavy borders
Use color as decoration — every use must signal a content type or state
Use font weights above 700 or below 400
Center-align body text — all prose is left-aligned for long-form reading
