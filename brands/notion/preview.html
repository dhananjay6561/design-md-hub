Guardrails
DO
Use #37352F for body text — never pure black
Use warm off-white #F7F6F3 for sidebar surfaces
Keep shadows barely visible — subtler than you think
Let whitespace carry the hierarchy, not color
Use color only for content-type tags and CTA
DON'T
Don't use pure #000000 black anywhere in the UI
Don't use heavy shadows or prominent borders
Don't use color as pure decoration
Don't go above font-weight 700
Don't center-align body or long-form text
