Guardrails
DO
Use electric-jade #ADF07E with dark text for the primary action
Use brand green #06AC38 for the mark, resolved state, and accents
Color status semantically: red triggered, amber acknowledged, green resolved
Set UI in Inter (≈ Plain), incident IDs / timestamps in JetBrains Mono
Keep operations surfaces dark (#09090B) — where on-call lives
DON'T
Put white text on jade or green buttons — contrast fails; use dark ink
Use green for a triggered/unresolved incident — green means resolved
Tint dark surfaces navy-heavy — the ops surface is near-black zinc
Render incident IDs or timestamps in a sans — mono carries the log
Fabricate incidents — use real SEV levels, service names, and a real lifecycle
