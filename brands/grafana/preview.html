Do
Keep panel chrome quiet — the visualization is the hero.
Use the fixed categorical palette so a series is the same color in every panel.
Color by threshold for state: green ok → yellow warning → red critical.
Use Roboto Mono for numbers, timestamps & queries; panel titles stay in Inter.
Don't
Recolor series arbitrarily or reuse one color for two series in a view.
Flood a dashboard with brand orange — it's the accent, not a data color (use #FF9830).
Add heavy shadows or big radii — Grafana is dense, square, and flat.
Let decoration compete with metrics; every pixel should carry signal.
