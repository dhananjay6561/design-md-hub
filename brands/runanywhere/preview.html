05 / Guardrails
Do & Don't
Do
Use the orange→red gradient for display; solid orange #FF6900 for controls
Darken orange to #D2470A for orange text/links on cream
Set hero & section display in the serif; body/UI in the sans
Keep the inference console dark in both themes
Don't
Don't set body text in the serif — it's display-only
Don't put orange text on the orange button
Don't invent metrics — use real inference language (tok/s, TTFT, kernels)
Don't use Math.random — keep the benchmark deterministic
