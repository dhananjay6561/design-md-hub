Do

        

          
Anchor on warm paper #F4EFEA + soft ink #383838 — keep pure black/white out of the base.

          
Use orange for actions, yellow for marquee/highlight blocks only, sky-blue for data & links.

          
Set the hero in Aeonik Fono, uppercase, wide tracking; SQL in Aeonik Mono, body in Inter.

          
Let the duck-and-cloud mascot carry the play; keep the working UI calm.

          
Show where compute ran — the local + cloud hybrid split is the point.

        

      

      

        
Don't

        

          
Don't use #FFDE00 for text — it fails contrast; it's a block color.

          
Don't mix the font roles (Fono display / Mono code / Inter body).

          
Don't invent evenly-lightened dark tints — the dark canvas is warm near-black #171613, borders translucent white.

          
Don't make table hover equal the base surface after the light swap.

          
Don't reduce MotherDuck to a plain query box — the hybrid + AI story is the identity.
