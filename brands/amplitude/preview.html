Guardrails
DO
Use brand blue #1E61F0 for primary actions, links, and the main chart series
Fill chart areas with the blue → purple gradient at low opacity — the signature look
Set headings in Gellix, body/UI in IBM Plex Sans, code in IBM Plex Mono
Color deltas semantically: green for uplift, red for decline
Keep light surfaces warm (#F5F4F0) — the warmth is part of the identity
DON'T
Set the brand blue on dark at #1E61F0 — contrast fails; lift to #3D6BFF
Use purple as a primary action — it's a data-viz accent, not a CTA
Set body or UI in Gellix — it's display only; IBM Plex Sans owns the UI
Cool the light neutrals to pure grey — Amplitude's off-white is warm
Fabricate chart data — plot a real, deterministic series
