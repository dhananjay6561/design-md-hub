Guardrails
Do
Keep surfaces monochrome (zinc); let a single --primary carry any color.
Drive everything from semantic tokens — never hardcode a hex on a component.
Separate with 1px --border, not shadows; scale corners with one --radius.
Use --muted-foreground for descriptions, --foreground for content.
Set primary-button text to --primary-foreground (Zinc flips, Orange goes dark).
Don't
Don't add a loud default brand hue — neutrality is the identity.
Don't lean on drop shadows for hierarchy — borders and spacing do the work.
Don't mix font roles — Geist for UI, Geist Mono for code/tokens.
Don't hardcode button text color, or a theme breaks in one mode.
Don't use Math.random() — the customizer presets are deterministic.
