Guardrails
DO
Use Docker Blue #1D63ED as the single primary — one confident blue, not a rainbow
Keep the whale mark blue; render it on white or navy, never on a busy photo
Keep surfaces neutral (white / #F4F6F9) and let the blue carry emphasis
Use green only for genuine "running / healthy / succeeded" states
Pair every status color with a label or dot — never color alone
DON'T
Use the old cyan #2496ED — the current brand blue is #1D63ED
Recolor the whale into gradients or off-brand hues
Use pure black #000 for dark surfaces — Docker's dark is navy-tinted (#0B1220)
Use the macOS traffic-light trio as decorative accents — terminal chrome / status only
Set display headings in the mono or body font — Space Grotesk owns headings
