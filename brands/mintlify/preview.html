Guardrails
Do
  • Use API method badges (GET/POST/PUT/DELETE) consistently
  • Use callout boxes to guide readers to key info
  • Show inline code with green tint for types and paths
  • Keep sidebar navigation clean — max 2 nesting levels
  • Make search a first-class navigation element
Don't
  • Don't use more than 4 heading levels per page
  • Don't overload the TOC sidebar — shorten the page
  • Don't use green for warning or danger callouts
  • Don't make code blocks feel like afterthoughts
  • Don't write in passive voice — "Run this" not "can be run"
