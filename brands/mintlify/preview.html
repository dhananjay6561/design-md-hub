Quickstart

Get started with Mintlify by deploying your documentation site in minutes and making your first content change with the web editor or Git.

Create your site
1

Install the Mintlify CLI globally.

$ npm i -g mint
2

Clone your repository and preview locally.

$ git clone <your-repository-url> $ mint dev
3

Push to deploy — changes go live automatically.

$ git add . && git commit -m "Update docs" $ git push
💡 Tip — Navigate to http://localhost:3000 to preview your docs locally before pushing changes.
Authentication

Mintlify supports multiple authentication methods for restricting access to your documentation. Protect internal content with JWT, OAuth, or password gating.

JWT authentication

Add an auth field to your mint.json configuration:

{ "auth": { "method": "jwt", "headerName": "Authorization" } }
Note — JWT authentication requires your server to sign tokens using the shared secret from your Mintlify dashboard.
Installation

The Mintlify CLI lets you develop and preview your documentation locally with hot reloading.

Requirements

Node.js 18 or later. Install globally via npm:

$ npm i -g mint $ mint --version
Tip — Run mint upgrade to update the CLI to the latest version.
Configuration

The mint.json file at your repository root controls all site configuration.

Basic setup
{ "name": "Acme Docs", "logo": { "light": "/logo/light.svg", "dark": "/logo/dark.svg" }, "primaryTab": { "name": "Docs" }, "navigation": [ { "group": "Getting Started", "pages": ["quickstart", "installation"] } ] }
MDX

Mintlify uses MDX — Markdown with JSX — so you can embed components directly in your documentation pages.

Frontmatter
--- title: "Introduction" description: "Your custom description here" --- Welcome to your new documentation site.
Components

Mintlify ships built-in components for callouts, tabs, cards, code groups, steps, and more — use them directly in MDX without any imports.

<Callout type="tip"> Use components to make your docs interactive. </Callout> <Card title="Quickstart" icon="bolt" href="/quickstart"> Get up and running in minutes. </Card>
Code Blocks

Code blocks support syntax highlighting for 100+ languages, optional line numbers, line highlights, and a copy-to-clipboard button.

```bash title="Install dependencies" npm i -g mint ``` ```typescript title="mintlify.config.ts" export default { name: 'My Docs', primaryTab: { name: 'Docs' }, } ```
Endpoints

Auto-generate beautiful API reference pages from an OpenAPI spec. Mintlify renders request/response schemas, authentication details, and a live playground.

"openapi": "openapi.yaml"
Tip — Mintlify supports OpenAPI 3.0 and 3.1. Point to a local file or a hosted URL.
Webhooks

Mintlify sends webhook events for page views, AI searches, and feedback submissions. Subscribe from your project dashboard under Settings → Webhooks.

Event types

Available events: page.viewed, search.performed, feedback.submitted.

Guardrails
DO
Use #fefdfb as the light mode page background — the warm off-white is Mintlify's most distinctive visual signature
Reserve ABCArizonaFlare for display headings and doc titles only; use Inter for all UI labels and body copy
Use #18e299 in dark mode and #0c8c5e in light mode — the two values are not interchangeable
Use PaperMono for code, metadata labels, nav group headings, and section identifiers
Use borders for surface separation — no drop shadows
DON'T
Use pure white (#ffffff) as the main page background in light mode — the warm cream is intentional
Render #18e299 directly on a light background — it fails WCAG contrast requirements
Alter the two-tone leaf mark — #18E299 / #0C8C5E is fixed in the SVG and must not change
Use font-weight above 600 for Inter in any UI context — Mintlify reads as medium-weight, not heavy
Use border-radius above 4px on interactive controls (buttons, inputs, selects)
