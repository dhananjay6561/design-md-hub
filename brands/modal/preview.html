import modal

app = modal.App("flux-inference")
image = (modal.Image.debian_slim()
    .pip_install("torch", "diffusers"))

@app.function(gpu="A100", image=image)
def generate(prompt: str):
    # cold-starts a GPU container on demand
    return pipe(prompt).images[0]

@app.local_entrypoint()
def main():
    prompts = load_prompts()  # 24 prompts
    # fan out across many GPUs, autoscaling
    for img in generate.map(prompts):
        img.save()

Do
Anchor on a warm near-black canvas; let neon green (#7FEE64) be the one signal color.
Use the cube motif — glowing green cubes as containers, the isometric cube-M as the mark.
Show the serverless story: containers cold-start, autoscale out, and scale to zero.
Headings in Goga (or a geometric-grotesque stand-in), body in Inter, all code & metrics in Fira Mono.
Give green a soft glow, not a heavy drop shadow.
Don't
Put green on a light/white canvas as the primary identity — Modal is dark-first, warm-black.
Introduce a second bright brand hue; orange/pink are sparing accents, not co-leads.
Use flat gray boxes for containers — they're lit green cubes.
Set code or metrics in the body/display font — the console is Fira Mono.
Render green as pure #00FF00 — it's the specific warm lime #7FEE64.
