DO
Use dbt orange #FE6703 for primary actions, the mark, and focused lineage
Put navy text on orange buttons — orange is too bright for white
Color DAG nodes by type: source-green, staging-blue, intermediate-purple, mart-orange
Set headings in Polymath (≈ Space Grotesk), model names / SQL in IBM Plex Mono
Use purple and lime as accents — the dbt energy without competing with orange
DON'T
Put white text on the orange button — contrast fails; use navy #101828
Use purple or lime as the primary action — orange owns "go"
Set model names or SQL in a sans — dbt is code-first; mono everywhere
Tint dark surfaces neutral-grey — dbt's dark is navy #101828
Fabricate a DAG — use real dbt naming (stg_, int_, fct_, dim_)
