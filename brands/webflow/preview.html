Guardrails
DO
Use Webflow blue #146EF5 for brand, CTAs, and canvas selection
Keep the Designer chrome dark regardless of the page theme
Use WF Visual Sans Mono for CSS values, class names, breakpoints
Use pastels as section backgrounds, not control colors
Show the selected element and its style values together
DON'T
Don't use the pre-rebrand indigo #4353FF — brand blue is #146EF5
Don't recolor the Webflow mark outside blue or a flat color
Don't put pastel fills on interactive controls
Don't set CSS values or class names in a proportional font
Don't invent dark surfaces; step within real #080808
