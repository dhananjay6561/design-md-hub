Guardrails
Do
  • Use teal only as an accent — highlight, not fill
  • Black text on teal buttons — contrast demands it
  • Use JetBrains Mono for all code, imports, CLI
  • Let whitespace breathe — minimalism is a feature
  • Show permission flags (--allow-net) distinctly
Don't
  • Don't add color variety — one teal is the whole palette
  • Don't use gradients — Deno is flat: black/white/teal
  • Don't round corners beyond 8px
  • Don't animate documentation content
  • Don't use teal for error or warning states
