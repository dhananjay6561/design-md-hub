Do
Keep the canvas warm off-white #F5F3F2 with near-black ink; use one electric lime as punctuation.
Make the primary button ink #1C1C1C; use lime only for the accent CTA, with black text.
Write test steps, selectors, CLI & eyebrows in Basically A Mono.
Color test state by meaning: green #3A9460 pass, amber running, red fail/bug.
Don't
Make lime the primary button, or put white text on lime — ink is primary.
Swap the warm paper for a cold grey — the warmth is part of the identity.
Set test steps or selectors in a proportional sans — they're mono.
Add a second saturated accent — lime is the only one.
