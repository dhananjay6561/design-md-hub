Do
  • Use monospace for all phone numbers, SIDs, webhooks
  • Color-code message status consistently
  • Show error codes prominently — devs need them fast
  • Twilio red IS the primary action color — use it confidently
  • Display delivery receipts with relative timestamps
Don't

  • Don't use light mode for the console
  • Don't use corners beyond 8px — enterprise grade
  • Don't show vague "failed" — always include error code
