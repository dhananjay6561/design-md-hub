DO
Anchor light UI on warm cream #FFF9F3 and dark on navy-black #0B0E14
Use the emotion spectrum for expression data (scores, bars) — that mapping is the product
Use lavender as the single accent (#8B5CC7 on cream, #C094E4 on ink); ink for buttons
Use Fellix for display/body, PP Fraktion Mono for scores, code and metadata
Use real product names (EVI, Octave, Expression Measurement) and real emotion labels
DON'T
Use pure white / pure black surfaces — Hume is warm cream + navy ink
Turn the whole UI rainbow — the spectrum is scoped to emotion data, not chrome
Swap Fellix or PP Fraktion Mono for generic substitutes — both are CORS-open
Invent emotion labels or randomize scores — real emotions, deterministic values
Put #C094E4 text on cream — it fails contrast; step to #8B5CC7
