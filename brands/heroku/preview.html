05 / Guardrails
Do & Don't
Do
Lead with brand purple #5A1BA9; use teal #5EEAD4 as the bright accent
Darken teal to #0E9A87 for teal text on light surfaces
Keep the build terminal dark in both themes
Call the runtime units “dynos”; use real buildpack language
Don't
Don't use teal #5EEAD4 as small text on white — it fails contrast
Don't put purple text on the purple primary button
Don't invent deploy copy — mirror real “-----> …” log phrasing
Don't use Math.random — keep the deploy deterministic
