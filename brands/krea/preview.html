Do
Keep the chrome monochrome — black, white, grey; let generations carry all color.
Invert the primary pill with theme (white-on-dark / black-on-light).
Use the twisting bloom mark in white/black + a clean Swiss grotesque.
Reserve --blue for realtime cues & links; keep other hues in generation frames.
Show the realtime feel — instant re-render + a latency cue.
Don't
Don't paint the UI with the generation palette — the work shines, not the chrome.
Don't use square, heavy buttons — Krea's actions are rounded pills.
Don't set type in a serif or quirky display face — it's neutral Suisse ≈ Inter.
Don't add a colored default accent to the chrome — monochrome is the point.
Don't use Math.random() — presets & renders are deterministic.
