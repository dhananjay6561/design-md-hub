05 / Guardrails
Do & Don't
Do
Lead with cyan-teal #00B7CA; use the teal→mint gradient for hero bands
Darken teal to #047B86 for teal text on white
Keep the canvas white; let the agent's work carry the color
Frame everything as a task the agent does
Don't
Don't treat Google Sign-In blue #1a73e8 as a brand color — it's a widget
Don't put teal text on the teal button
Don't invent agent output — mirror real task types
Don't use Math.random — keep runs deterministic
