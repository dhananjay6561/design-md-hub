DO

  • Use status dots consistently — green/orange/blue/grey only
  • Use blue for all primary actions (Save, Publish)
  • Distinguish environments visually with colored dots
  • Show field types with colored badges in content type editor
  • Keep entry lists scannable: name, type, status at a glance

DON'T

  • Don't use green for anything except "published" state
  • Don't mix content type icon colors across contexts
  • Don't show raw API responses in editor view
  • Don't show more than 2 hover actions on entries
  • Don't render rich text as plain text in previews
