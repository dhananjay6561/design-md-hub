DO
Use teal for PPG features and indigo for ORM features — never swap them
Always use Mona Sans for display headings and primary CTAs
Show schema types in monospace with keyword coloring (model, @id, @default)
Include @default and @relation decorators in all schema examples
Default to dark theme — Prisma is dark-first across all surfaces
DON'T
Mix PPG teal and ORM indigo colors in a single component
Use generic sans-serif for schema code blocks or Prisma Client calls
Round corners above 12px on data panels, tables, or code blocks
Show untyped JavaScript where TypeScript is expected in examples
Use teal as a generic brand accent outside of Postgres contexts
