Tone & Guardrails

5 + 5
Do
Default to dark theme — it's the primary experience
Keep UI dense; whitespace is earned, not default
Use the purple accent only for selection, focus, and active state
Make interactions feel instant — 100ms max hover transitions
Use keyboard shortcuts everywhere; surface them in tooltips
Don't
Use rounded corners larger than 8px
Add decorative gradients, illustrations, or hero images
Use color for anything other than status, priority, and labels
Add loading spinners where optimistic UI is possible
Use modals for simple confirmations — prefer inline or toast
