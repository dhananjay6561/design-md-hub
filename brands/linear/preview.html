Do
Default to dark and keep the UI dense — whitespace is earned.
Use the bright #7170FF accent on dark; reserve it for selection, focus & active.
Let color mean something — status, priority, label — never decoration.
Set the UI in Inter with cv01 + ss03; make interactions instant (~100ms).
Don't
Use corners larger than ~8px, or add gradients, illustrations, or hero images.
Use the accent as a large fill — it's punctuation.
Add spinners where optimistic UI works; prefer inline/toast over modals.
Invent cold-grey text tints — Linear's greys are calibrated (#8A8F98).
