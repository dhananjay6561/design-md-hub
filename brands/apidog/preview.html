Do
Keep a bright white / pale-blue canvas with deep navy ink — light is primary.
Use one blue→cyan gradient (#1A66FF→#00AAFF) for mark, hero, Send and active states.
Set marketing display in Poppins; keep dense product UI in Inter, code in JetBrains Mono.
Make schema validation visible — responses checked against the designed spec (the design-first edge).
Color HTTP methods & statuses as functional signals only.
Don't
Present Apidog as just a request-runner — it's design + test in one.
Introduce a competing brand hue; blue→cyan is the only brand family (navy is the ink).
Set body or dense tables in Poppins — the rounded display is for headings/wordmark.
Make the gradient neon or muddy — clean royal-blue warming to cyan.
Swap the X-and-bone mark for a generic API / globe icon.
