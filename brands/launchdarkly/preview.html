DO
Use electric lime #EBFF38 for brand accent and primary CTAs
Use blue #405BFF for the targeting-on toggle and interactive state
Keep flag keys, variations, and targeting rules in the mono stack
Show each environment's flag state independently
Keep surfaces near-black neutral so lime and blue lead
DON'T
Don't fill the wordmark with lime — it stays an accent
Don't invent navy dark surfaces; LaunchDarkly's dark is neutral
Don't use lime for destructive or error states
Don't set flag keys or variations in a proportional font
Don't imply a flag is global — always scope it to an environment
