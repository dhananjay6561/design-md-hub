Guardrails
DO
Use #8a05ff as the sole primary brand color — all interactive elements trace back to this one value
Reserve green (#00db7c) strictly for live and success states — it is semantic, not decorative
Use dark purple (#1c0037, #48008c) for dark mode feature cards and hero sections
Keep fill="currentColor" on the mark and wordmark — both adapt to dark/light automatically
Use the diagonal staircase mark exactly as is — it is Render's most distinctive visual element
DON'T
Use green as a decorative accent — it signals "live" and nothing else in the Render vocabulary
Use orange (#d67f2e) anywhere except the hero H1 gradient
Place bright purple #8a05ff as a background — it's a foreground/border/icon color only
Add elevation shadows — Render uses subtle borders for surface hierarchy, not shadows
Mix the three font roles: Roobert is headings-only, PPNeueMontreal is UI, Mono is code
