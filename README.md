# design-md-hub

A curated collection of `DESIGN.md` files — plain-text design system documents that AI agents read to generate consistent, on-brand UI.

Drop a `DESIGN.md` into your project and let coding agents generate a matching interface.

## What is a DESIGN.md?

A `DESIGN.md` is a single markdown file that describes a brand's visual language:

- Color palettes & semantic tokens
- Typography scale & font choices
- Component patterns & variants
- Spacing, shadows, border radius
- Layout principles & responsive behavior
- Tone, guardrails & dos/don'ts

AI coding agents (Claude, Cursor, Copilot, etc.) read this file to generate UI that looks and feels like the real thing.

## How to Use

1. Pick a `DESIGN.md` from the collection above
2. Copy it into the root of your project
3. Tell your AI agent: *"Follow the DESIGN.md in the root of this project"*
4. Generate UI components, pages, or entire apps with consistent styling
